# SpaceX-Capstone-Project
IBM Data Science Capstone Project analyzing SpaceX launch data using Python, SQL, data visualization, Plotly Dash, Folium, and machine learning.
This repository contains my final capstone project for the IBM Data Science Professional Certificate. 

The project analyzes spaceX Falcon 9 launch data to explore the factors associated with successful first-stage landings.

## Project Objectives 

The project uses data science techniques to:

- Collect SpaceX launch data 
- Clean and wrangle the data
- Explore launch patterns using Python and SQL
- Visualize launch sites and nearby geographic features
- Build an interactive Plotly Dash dashboard 
- Create interactive maps with Folium
- Build and evaluate machine learning classification models
